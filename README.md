# Haotian Zheng — Academic Homepage

A lightweight, responsive academic website for GitHub Pages. The publishable files live at the repository root; no build step or package installation is needed.

## Publish on GitHub Pages

1. Create a public GitHub repository named `HaotianZheng-Econ.github.io`.
2. Upload this complete project and push it to the `main` branch.
3. Open **Settings → Pages → Build and deployment**.
4. Choose **Deploy from a branch**, then select `main` and `/ (root)`.

The published site address is `https://haotianzheng-econ.github.io/`.

## Design note

The information structure and restrained academic style were inspired by [Yang Gao's academic homepage](https://yanggaolamb.github.io/). Her public repository does not include a licence, so this project uses independently written HTML and CSS and does not copy her custom code, text, portrait, icons, or tracking scripts.
